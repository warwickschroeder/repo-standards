# repo-standards

Plugins and blueprints that other repositories install: the modular monolith blueprint, app documentation, regression runbooks, smoke tests and PR bodies.

## Where trackable work lives

**Every defect, enhancement, feature idea and deferred decision is a GitHub issue on `warwickschroeder/repo-standards`, one issue per item.** Search before raising, closed issues included (`gh issue list --search "<terms>" --state all`), and reopen or update an existing issue rather than raising a second one about the same thing.
